เชื่อม Supabase

ตั้งค่าครั้งเดียว แล้วใช้งานได้เลย ข้อมูลจะถูกเก็บในเบราว์เซอร์ (localStorage) ไม่ส่งออกที่ไหน

  2. ที่ Supabase → Project Settings → API คัดลอก URL และ anon public key
  3. วางลงช่องด้านล่าง → กด บันทึก
